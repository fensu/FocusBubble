# Focus Bubble

ADHD 友好的桌面视觉聚焦工具。鼠标周围保持清晰，外围区域轻微降低亮度并模糊，帮助注意力留在当前任务上，而不是被屏幕角落的内容不断拉走。

完全开源、完全本地运行：无账号、无云端、无数据上报，所有设置只保存在本机。

> ⚠️ **健康与安全警告**
>
> 本软件会持续改变屏幕的亮度与清晰度分布。**使用过程中如出现频闪、眼痛、头痛、眩晕或视觉异常，请立即关闭本软件并休息。** 有光敏性癫痫、偏头痛病史或眼部疾病者，请在使用前咨询医生。首次启动时会显示本提示，效果默认关闭，确认了解后手动开启。

## 功能

### 两种聚焦模式

| 模式 | 说明 |
| --- | --- |
| 气泡 | 鼠标周围的椭圆清晰区，横向/纵向可独立拉伸 |
| 横带 | 宽度和高度都可调的圆角矩形清晰区，中心可相对鼠标偏移（面板内遥控器式方向键调节） |

### 模糊的实现逻辑

外围模糊走各平台的原生渲染路径：Windows 通过系统桌面捕获把画面交给显卡着色器处理，macOS 使用系统毛玻璃效果（无需屏幕录制权限）。渲染路径不可用时自动回退为 Canvas 暗化（无模糊）。

### 视觉舒适度

- 默认外围暗度温和（约 30%），宽羽化过渡，无亮暗硬边
- 清晰区平滑跟随鼠标；快速移动时遮罩自动变柔和，避免"探照灯"式晃眼
- 预设：低动态（弱暗化 + 大羽化 + 慢跟随）/ 强聚焦（短时高强度）

### 其他

- 系统托盘：开关效果 / 打开面板 / 退出；关闭窗口默认最小化到托盘
- 应用内手动检查更新，后台下载安装
- 7 种界面语言：中文、English、日本語、한국어、Deutsch、Français、Español
- 参数按平台分开保存，互不干扰

## 快速上手

- **Windows**：打开面板 → 点「启动直通」（启用 GPU 渲染）→ 确认右上角「效果」为开启状态。**两个开关都打开**才有完整模糊遮罩；只开直通不开效果则只显示原图。效果关闭时状态面板会出现警告提示。
- **macOS**：无需直通开关，「效果」开启即有毛玻璃遮罩。
- 通用：模式与各滑块实时生效，「恢复默认」一键还原。

## 常见问题

- **macOS 安装后打不开？** 首次运行需在 系统设置 → 隐私与安全性 中允许 Focus Bubble（未签名应用的标准流程：右键应用图标 → 打开，或在设置里点"仍要打开"）。
- **Windows 10 屏幕边缘出现黄色边框？** 正常现象，这是系统对屏幕捕获的隐私提示，不影响使用（Windows 11 无此提示）。
- **开启了直通但没有遮罩效果？** 检查面板右上角的「效果」开关是否开启——直通与效果是两个独立开关，状态面板会在效果关闭时给出警告提示。

## 运行与开发

环境要求：

- Node.js ≥ 20.19（建议 22 LTS）
- Rust stable（通过 [rustup](https://rustup.rs/) 安装，Windows 需含 MSVC 工具链）
- Windows 10 1903+ 或 macOS 12+

```bash
npm install          # 安装前端依赖
npm run desktop:dev  # 开发模式（热更新）
```

本地打包 `npm run tauri build`；各平台安装包见 [GitHub Releases](https://github.com/fensu/FocusBubble/releases)。
