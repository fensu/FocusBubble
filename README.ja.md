# Focus Bubble

[简体中文](README.md) | [English](README.en.md) | **日本語**

ADHD に配慮したデスクトップ用ビジュアルフォーカスツール。マウス周辺をクリアなまま保ち、周辺領域を穏やかに暗くぼかすことで、画面の隅のコンテンツに注意を奪われることなく現在のタスクに集中できます。

完全オープンソース・完全ローカル動作：アカウント不要、クラウド不要、テレメトリなし。設定はすべて本体に保存されます。

> ⚠️ **健康と安全に関する警告**
>
> 本ソフトは画面の明るさと明瞭さの分布を継続的に変化させます。**使用中にちらつき、目の痛み、頭痛、めまい、視覚異常が生じた場合は、すぐにアプリを終了して休憩してください。** 光感受性てんかん・偏頭痛・目の疾患の既往がある方は使用前に医師へ相談してください。初回起動時にこの注意が表示され、効果はデフォルトでオフです。確認のうえ手動でオンしてください。

## 機能

### 2 つのフォーカスモード

| モード | 説明 |
| --- | --- |
| バブル | マウス周辺の楕円形クリア領域。横・縦のストレッチを独立して調整可能 |
| バンド | 幅と高さを調整できる角丸矩形クリア領域。中心をマウスからオフセット可能（パネル内のリモコン式操作） |

各モードはフェザー・ぼかし・暗さ・追従の設定をそれぞれ独立して保持し、一方を調整しても他方に影響しません。

### ぼかしの実装

周辺のぼかしは各プラットフォームのネイティブ描画パスを使用します。Windows はシステムのデスクトップキャプチャを GPU シェーダーで処理し、macOS はシステムの毛玻璃（スケオモルフィズム）効果を使用します（画面収録権限は不要）。ネイティブパスが利用できない場合は Canvas の暗色化（ぼかしなし）にフォールバックします。

### ビジュアルコンフォート

- デフォルトの周辺暗さは穏やか（約 30%）で、広いフェザーによる滑らかな推移。明暗の硬い境界はありません
- クリア領域はマウスを滑らかに追従。高速移動時はマスクが自動的に柔らかくなり、「サーチライト」的な目の刺激を回避
- プリセット：低ダイナミック（弱い暗さ + 広いフェザー + 遅い追従）／強フォーカス（短時間の高強度）

### その他

- システムトレイ：効果のオン/オフ、パネルを開く、終了。ウィンドウを閉じるとデフォルトでトレイに最小化
- アプリ内の手動アップデート確認（バックグラウンドでダウンロード・インストール）
- 7 言語対応：中文、English、日本語、한국어、Deutsch、Français、Español
- 設定はプラットフォームごとに分離保存され、相互に干渉しません

## よくある質問

- **macOS でアプリが開けない？** 初回起動時は システム設定 → プライバシーとセキュリティ で Focus Bubble を許可してください（未署名アプリの標準フロー：アプリアイコンを右クリック → 開く、または設定で「このまま開く」）。
- **Windows 10 で画面の周りに黄色い枠が出る？** 正常な動作です。画面キャプチャに対するシステムのプライバシー表示で、使用には影響しません（Windows 11 では表示されません）。
- **パススルーをオンにしてもマスクが出ない？** 右上の「効果」スイッチを確認してください。パススルーと効果は独立した 2 つのスイッチで、効果がオフの間はステータスパネルに警告が表示されます。

## 使い方

- **Windows**：パネルを開く →「パススルー開始」をクリック（GPU 描画を有効化）→「効果」がオンになっていることを確認。**両方のスイッチがオン**で完全なぼかしマスクが表示されます。効果がオフの間はステータスパネルに警告が出ます。
- **macOS**：パススルーのスイッチは不要。「効果」をオンにするだけで毛玻璃マスクが表示されます。
- 共通：モードとスライダーはリアルタイムで反映。「デフォルトに戻す」で一括リセット。

## 開発

要件：

- Node.js ≥ 20.19（22 LTS 推奨）
- [rustup](https://rustup.rs/) でインストールした Rust stable（Windows は MSVC ツールチェーン）
- Windows 10 1903+ または macOS 12+

```bash
npm install          # フロントエンド依存のインストール
npm run desktop:dev  # 開発モード（ホットリロード）
```

ローカルビルドは `npm run tauri build`。各プラットフォームのインストーラーは [GitHub Releases](https://github.com/fensu/FocusBubble/releases) にあります。

